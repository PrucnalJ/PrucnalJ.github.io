Title

titlebm.com

Co-Founder & CTO

An RCS Business Messaging platform that lets brands send rich, verified, interactive messages straight into the native inbox. I lead architecture and write most of the code.

  • ~315K lines of TypeScript across 289 API endpoints, a 124-table Postgres schema with row-level security, and 18 Inngest background jobs.
  • A provider-agnostic RCS/SMS abstraction layer over Pinnacle, Twilio and four SMS carriers — per-brand credential resolution, template caching, HMAC signature verification and TCPA-compliant keyword handling.
  • “Studio”, a React Flow visual automation engine with branching, delays, recurring schedules and inbound webhook triggers, compiled through a Zod-validated FlowIntent contract with an AI self-repair loop.
  • An AI agent on the Claude API (42 tools) and an MCP server (39 tools, OAuth 2.1 + PKCE) with an eval harness for regression testing — external AI assistants can operate the platform end to end.
  • 13+ integrations (HubSpot, Shopify, Clover, Mindbody, a GoHighLevel marketplace app) plus full Stripe billing with a credit ledger, auto-reload and usage analytics.
